# Sentence Anatomy Lab

Interactive clause-chunking tool for lower-ability DSE English S4 students.

## Features
- Paste any complex sentence → colour-coded view + anatomy tree + chunking tips
- Covers relative clauses, reduced relatives/participles, adverbial participles, noun clauses, passive
- Learn Structures, Writing Transfer, Sample Bank
- Students can save sentences under fixed themes (localStorage)

## LLM Analysis (optional)
Click the gear icon (⚙️) in the header to enter your OpenAI-compatible API key.
- Key is stored only in the browser (localStorage)
- Works with OpenRouter, OpenAI, xAI Grok, etc.
- If the key is blank or the call fails, it falls back to the built-in rule-based analyser
